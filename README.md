# Class Weaver

สร้าง Web App เพื่อช่วยในการสร้างไฟล์ข้อมูล GameFlow ผสมกับ Class Object แบบ C#

มี Page หลักๆตามนี้
Page 1: User สามารถสร้าง Class Object โดยเลือกได้ว่าสามารถมี Parameter Field ประเภทไหนได้บ้าง สามารถเพิ่มลด Parameter ได้ เปลี่ยนชื่อได้ และสามารถให้ Parameter Field เป็น Class Object ที่เคยสร้างไว้แล้วได้ด้วย รวมถึงสามารถ Inherit จาก Class Object ที่เคยสร้างได้เช่นกัน
Page 2: User สามารถสร้าง Card ที่มีโครงสร้างข้อมูลตาม Class Object ที่เลือก และสามารถ Export เป็นไฟล์ txt Json หรือ export ทั้งหมดเป็น zip ได้
